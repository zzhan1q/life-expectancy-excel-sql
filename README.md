# Восстановление продолжительности жизни после 2019 года

В 165 из 196 экономик, где после 2019 года отмечалось снижение, показатель к 2023-му вернулся к уровню 2019-го или превысил его. Для попадания в выборку достаточно одного наблюдения ниже базы в 2020–2022 годах.

[Книга Excel](report.xlsx) · [Запрос SQLite](analysis.sql) · [Результаты CSV](summary.csv)

`EXISTS` отбирает экономики с падением после 2019 года. Затем SQL и Excel сравнивают 2023 год с базой. Лист «Сверка» показывает пропуски по году и расхождения между формулами и SQL.

В выборке только экономики со снижением хотя бы в одном из 2020–2022 годов и с данными за 2019 и 2023 годы. Сравнение не оценивает причины снижения.

**Источник.** Всемирный банк, World Development Indicators: [`SP.DYN.LE00.IN`](https://data.worldbank.org/indicator/SP.DYN.LE00.IN). В `source.csv` оставлены национальные ряды за 2010–2023 годы; региональные и глобальные агрегаты исключены. [Лицензия набора](https://datacatalog.worldbank.org/infrastructure-data/search/dataset/0037712/world-development-indicators). Дата выгрузки: 23 ноября 2026 года. Пустая ячейка означает отсутствие наблюдения.
